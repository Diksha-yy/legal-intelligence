# Legal Intelligence Evaluation Datasets

All pilot data is synthetic and intended for software
evaluation only.

## Data files

- m1_ocr.csv
- m2_classification.csv
- m3_summarization.csv
- m4_translation.csv
- m5_missing_clauses.csv
- m6_risk_scoring.csv
- m7_fairness.csv
- m8_rag.csv
- m9_comparison.csv

## Ground truth

Expected outputs must be reviewed and fixed before running
the final evaluation.

Synthetic pilot results must not be presented as independent
real-world legal performance.

Development data and final held-out test data must be kept
separate.

## Limitations

The data does not establish legal validity, enforceability,
fairness, or suitability for actual legal decisions.
